🎯 ENDPOINTS NUEVOS
═════════════════════════════════════════════════════════════════════════════════

1. POST /api/leads/:leadId/convertir-a-oportunidad
   ├─ Convertir lead a oportunidad manualmente
   ├─ Req: { titulo?, proyecto?, propiedad?, valor?, probabilidad? }
   └─ Res: { exito, oportunidad }

2. GET /api/leads/no-convertidos/lista?limite=10
   ├─ Obtener leads sin oportunidades activas
   ├─ Útil para dashboard
   └─ Res: { exito, total, leads }

3. GET /api/leads/:leadId/oportunidades
   ├─ Obtener todas las oportunidades de un lead
   └─ Res: { exito, total, oportunidades }

4. GET /api/leads/estadisticas/conversion
   ├─ Estadísticas de conversión lead → oportunidad
   ├─ Res: { exito, estadisticas: {
   │    totalLeads,
   │    leadsConOportunidad,
   │    leadsSinOportunidad,
   │    oportunidadesGanadasDesdeLead,
   │    valorGanado,
   │    tazaConversion %
   │ }}
   └─ Ideal para widget de dashboard

5. POST /api/leads/:leadId/completar-alerta-y-convertir
   ├─ Todo-en-uno: Completa alerta + marca lead como contactado
   ├─ + Crea oportunidad automáticamente
   ├─ Req: { alertaId, notas? }
   └─ Res: { exito, mensaje }

🧪 CASOS DE USO Y PRUEBAS
═════════════════════════════════════════════════════════════════════════════════

Caso 1: Nuevo Lead → Alerta → Contacto
────────────────────────────────────────
1. POST /api/contactos { nombre, tipo: 'LEAD' }
   → Lead creado (NUEVO)

2. [Esperar 24h o forzar] POST /api/alertas/generar
   → AlertaLead creada

3. Usuario ve alerta en dashboard
   → Puede completarla manualmente O
   → Usar endpoint: POST /api/leads/:id/completar-alerta-y-convertir

4. Flujo automático:
   ✅ AlertaLead.completada = true
   ✅ Contacto.estadoLead = CONTACTADO
   ✅ OportunidadCliente creada en etapa CONTACTO
   ✅ Contacto.fechaSeguimiento actualizado

Caso 2: Lead a Cliente Ganado
──────────────────────────────
1. Lead (NUEVO, sin oportunidad)
   
2. → CONTACTADO (con oportunidad CONTACTO)
   [después de completar alerta]
   
3. → CONTACTADO (con oportunidad VISITA)
   [usuario mueve en pipeline]
   
4. → CONTACTADO (con oportunidad NEGOCIACIÓN)
   
5. → CONTACTADO (con oportunidad CIERRE)
   
6. → CONVERTIDO (con oportunidad GANADO) ✅
   [usuario marca como ganada]
   ├─ Lead.fechaConversion = ahora
   ├─ Lead.estadoLead = CONVERTIDO
   └─ Registro completo en estadísticas


🔍 TESTING RECOMENDADO

3. Mover oportunidad y sincronizar:
   PATCH /api/oportunidades/:id/etapa { etapa: 'VISITA' }
   → GET /api/contactos/:id → estadoLead debe ser CONTACTADO

4. Ganar oportunidad:
   PATCH /api/oportunidades/:id/etapa { etapa: 'GANADO' }
   → GET /api/contactos/:id → estadoLead debe ser CONVERTIDO
   → GET /api/leads/estadisticas/conversion → tazaConversion debe aumentar
