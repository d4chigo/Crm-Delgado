                    SISTEMA MCP IMPLEMENTADO

✅ COMPLETADO: Sistema MCP para análisis de datos CRM con Gemini

================================================================================
                         QUÉ SE IMPLEMENTÓ
================================================================================

1. BACKEND MCP (server/src/services/mcpService.ts)
   - Análisis completo del CRM con datos reales de BD
   - Generación automática de insights de marketing
   - Filtrado avanzado de leads
   - Estadísticas por agente
   - Búsqueda de contactos
   - Oportunidades activas
   - Actividad reciente

2. ENDPOINTS API (server/src/routes/mcp.ts)
   GET /api/mcp/analysis              → Análisis del CRM
   GET /api/mcp/marketing-insights    → Insights de marketing
   GET /api/mcp/leads                 → Leads con filtros
   GET /api/mcp/clientes              → Clientes con proyectos
   GET /api/mcp/oportunidades         → Oportunidades activas
   GET /api/mcp/actividad             → Actividad reciente
   GET /api/mcp/contacto/:correo      → Buscar contacto
   GET /api/mcp/estadisticas-agentes  → Desempeño de agentes

3. HERRAMIENTAS GEMINI (botcrm/services/tools.ts)
   ✓ getLeadsFiltered        - Filtrar leads avanzado
   ✓ getOportunidadesActivas - Oportunidades activas
   ✓ getActividadReciente    - Actividad de días
   ✓ buscarContacto          - Buscar por correo
   ✓ getEstadisticasAgentes  - Desempeño de agentes
   + Herramientas existentes (crear, actualizar, eliminar contactos)

4. INTEGRACIÓN FRONTEND (botcrm/services/)
   - crmDataService.ts actualizado para usar endpoints MCP
   - geminiService.ts mejorado con nuevas herramientas
   - Análisis de marketing basado en datos reales

5. INSTRUCCIONES GEMINI (botcrm/constants.ts)
   - Sistema de instrucciones optimizado para análisis
   - Prioridades de análisis definidas
   - Contexto del negocio incluido

================================================================================
                         CÓMO USAR
================================================================================

1. INICIAR SERVIDOR
   cd server
   npm install (si no lo hiciste)
   npm run dev
   
   Deberías ver: "🚀 Servidor corriendo en http://localhost:5000"

2. INICIAR FRONTEND
   cd botcrm
   npm install (si no lo hiciste)
   npm run dev
   
   Deberías ver: "Local: http://localhost:5173"

3. CONFIGURAR VARIABLES DE ENTORNO
   
   server/.env:
   DATABASE_URL=mysql://usuario:contraseña@localhost:3306/crm_delgado
   GOOGLE_API_KEY=tu_clave_gemini
   PORT=5000
   
   botcrm/.env.local:
   VITE_API_URL=http://localhost:5000/api
   VITE_GOOGLE_API_KEY=tu_clave_gemini

4. USAR EL CHATBOT
   Abre http://localhost:5173 y prueba:
   
   "¿Cuál es mi tasa de conversión?"
   "¿Qué debo mejorar en mi marketing?"
   "¿Cuántos leads tengo sin calificar?"
   "Busca el contacto juan@ejemplo.com"
   "¿Cuáles son mis oportunidades activas?"
   "¿Cómo está el desempeño de mis agentes?"

================================================================================
                    INSIGHTS GENERADOS AUTOMÁTICAMENTE
================================================================================

El sistema genera insights como:

🔴 ALTA PRIORIDAD
   - Tasa de conversión baja
   - Muchos leads sin calificar
   - Cotizaciones pendientes
   - Concentración geográfica alta

🟡 MEDIA PRIORIDAD
   - Fuentes principales de leads
   - Análisis de ubicaciones
   - Gestión de proyectos

🟢 BAJA PRIORIDAD
   - Excelente tasa de conversión
   - Oportunidades de ingresos

Cada insight incluye:
- Descripción del problema
- Acción recomendada
- Impacto estimado

================================================================================
                         TROUBLESHOOTING
================================================================================

Error: "No se pudieron obtener las estadísticas"
→ Verifica que el servidor está corriendo
→ Revisa la conexión a BD en server/.env

Error: "Contacto no encontrado"
→ Verifica que el correo es correcto
→ Asegúrate de que el contacto existe en BD

Error: "API Key no configurada"
→ Agrega VITE_GOOGLE_API_KEY en botcrm/.env.local
→ O configura en localStorage desde consola del navegador

Puerto 5000 en uso:
→ Cambia PORT en server/.env a otro puerto (ej: 5001)
