================================================================================
                    CRM DELGADO - APLICACIÓN DE ESCRITORIO
================================================================================

¡BIENVENIDO! Este archivo te guiará para ejecutar tu CRM como aplicación de 
escritorio de manera fácil y correcta.

REQUISITOS:
✓ Node.js 18+ (https://nodejs.org/)
  - Incluye npm automáticamente
  - Verifica con: node --version

================================================================================
                         INICIO RÁPIDO (3 PASOS)
================================================================================

PASO 1: INSTALACIÓN INICIAL (Primera vez solamente)
-----------------------------------------------------
Abre terminal en la carpeta del proyecto y ejecuta:

    npm run instalar

⏱️  Tiempo: 3-5 minutos (depende de tu conexión)
✅ Se instalarán todas las dependencias automáticamente

PASO 2: EJECUTAR LA APLICACIÓN
------------------------------
Después de instalar, simplemente ejecuta:

    npm run dev

✅ Esto iniciará:
   - Servidor backend (Puerto 5000)
   - Cliente frontend (Puerto 3000)
   - Ventana de Electron (aplicación de escritorio)
   
⏱️  Tiempo: 30-60 segundos hasta que la aplicación esté lista

PASO 3: USAR LA APLICACIÓN
--------------------------
La ventana de Electron se abrirá automáticamente
¡Tu CRM está listo para usar!

================================================================================
                         TODOS LOS COMANDOS DISPONIBLES
================================================================================

INSTALACIÓN Y EJECUCIÓN:
  npm run instalar              - Instala todas las dependencias
  npm run dev                   - Inicia servidor, cliente y Electron ⭐

SCRIPTS RÁPIDOS:
  iniciar-rapido.bat            - Windows (doble clic)
  bash iniciar-rapido.sh        - Linux/Mac
  .\ejecutar-crm.ps1           - Windows (PowerShell)

COMPILACIÓN:
  npm run compilar              - Compila TODO para producción
  npm run compilar:cliente      - Solo compila el frontend
  npm run compilar:servidor     - Solo compila el backend
  npm run compilar:electron     - Solo compila Electron

EMPAQUETAMIENTO (Crear instalador):
  npm run empaquetar            - Crea instalador Windows (.exe)
  npm run empaquetar:mac        - Crea instalador macOS (.dmg)
  npm run empaquetar:linux      - Crea instalador Linux (.AppImage)

================================================================================
                              FLUJO DE EJECUCIÓN
================================================================================

1. Usuario ejecuta: npm run dev (o .\ejecutar-crm.ps1)
2. Se instalan dependencias (si es primera vez)
3. Se inicia servidor backend en puerto 5000
4. Se inicia cliente frontend en puerto 3000
5. Se abre ventana de Electron
6. Se cargan migraciones de BD automáticamente
7. ✅ Aplicación lista para usar

================================================================================
                        INFORMACIÓN IMPORTANTE
================================================================================

PUERTOS UTILIZADOS:
  Backend:  http://localhost:5000 (API)
  Frontend: http://localhost:3000 (Interfaz)
  Electron: Ventana nativa (aplicación de escritorio)

BASES DE DATOS:
  Por defecto: SQLite (archivo local: server/dev.db)
  Para cambiar a MySQL/PostgreSQL: edita server/prisma/schema.prisma

VARIABLES DE ENTORNO:
  Se crean automáticamente en .env
  Si necesitas editar valores: abre .env con un editor de texto

LOGS Y ERRORES:
  Si algo falla, verás mensajes en la terminal
  Para más detalles: abre Developer Tools (F12) en Electron

================================================================================
                            DETENER LA APLICACIÓN
================================================================================

OPCIÓN 1: Cierra la ventana de Electron
  - El backend y frontend se detienen automáticamente

OPCIÓN 2: En la terminal
  - Presiona Ctrl+C

================================================================================
                          ¿ALGO NO FUNCIONA?
================================================================================

Revisa estos archivos en el proyecto:

  📄 GUIA-ESCRITORIO.md      - Guía completa y detallada
  🔧 TROUBLESHOOTING.md      - Solución de problemas comunes

O ejecuta el comando de diagnóstico:
  
  npm run instalar

Esto limpiará todo e instalará nuevamente correctamente.

El archivo .env contiene:
- DATABASE_URL: Conexión a la BD
- NODE_ENV: Entorno (development/production)
- PORT: Puerto del servidor
- JWT_SECRET: Secreto para tokens
- CORS_ORIGIN: Origen permitido

================================================================================
                              SOLUCIÓN DE PROBLEMAS
================================================================================

❌ "Node.js no está instalado"
   → Descarga e instala Node.js desde https://nodejs.org/

❌ "El puerto 5000 está en uso"
   → Cambia PUERTO_SERVIDOR en app/services/servicio-servidor.ts

❌ "Error de migraciones"
   → Ejecuta: cd server && npm run dev

❌ "No se puede cargar la interfaz"
   → Verifica que el cliente está compilado: npm run compilar:cliente
